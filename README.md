# Papercut releases

Builds of Papercut for the hosts and listeners, and the update feed (`appcast.xml`) the app checks once a day. The source is private.

First install: download the newest `Papercut-<version>.dmg` from [Releases](https://github.com/screenspacelab/papercut-releases/releases) and drag Papercut into Applications. After that, Papercut updates itself (Papercut → Check for Updates… checks right away).
